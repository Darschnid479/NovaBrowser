NOVA

Fast to reach. Easy to make yours.

Built around the browser experience.

NOVA uses WebView2 for web compatibility while focusing its own code on tabs, navigation, themes, permissions, privacy controls, and the Windows interface around the web.

◫

Multi-tab browsing

Normal and private tabs, session restore, recently closed tabs, and keyboard-first switching.

✦

Deep personalization

Multiple themes, accents, backgrounds, motion preferences, and a guided first-run setup.

⌘

Command palette

Quickly reach actions, tabs, and searches from a single keyboard-driven command surface.

⌕

Your search engine

Choose Google, DuckDuckGo, or Bing during setup and change the choice later.

◇

Permission-aware

Camera, microphone, location, notifications, and clipboard requests are surfaced visibly.

◉

Windows native UI

WPF, custom vector icons, local settings, and a desktop-first interface written in Visual Basic .NET.

Simple stack. Clear direction.

NOVA is intentionally transparent about what it is: a custom browser shell around Microsoft's WebView2, not a brand-new rendering engine.
